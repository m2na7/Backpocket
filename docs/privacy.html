Backpocket — Privacy Policy

Last updated: 2 September 2026

Backpocket is a clipboard manager. It sees everything you copy, which is exactly why this page is short and specific rather than long and vague.

What Backpocket collects

Nothing. There is no account, no sign-in, no sync, no analytics, no telemetry, no crash reporting, and no server that belongs to this project holding anything you copy or write.

Where your data lives

Your clipboard history and notes are stored on your Mac and nowhere else, in ~/Library/Application Support/Backpocket — or, for the Mac App Store version, inside the app's own sandbox container. Delete that folder and the data is gone. It is never uploaded.

What is deliberately not recorded

Backpocket honours the pasteboard markers apps use to say "do not keep this": org.nspasteboard.ConcealedType, which password managers set, along with TransientType and AutoGeneratedType. Anything marked that way is ignored rather than stored. You can also exclude any application entirely, so nothing copied from it is ever recorded.

When Backpocket uses the network

Two things reach the internet, both under your control, and neither ever carries what you copied.

Link favicons. When a saved link is shown, Backpocket may request that site's icon over HTTPS — from the linked site's own domain, never a third-party favicon service, and never a local or private address. The request carries no data about you beyond what any web request carries: an IP address and a timestamp. It is made through a session that stores no cookies. Turn it off in Settings › Clipboard and no request is made at all.

Update checks (direct download only). The version downloaded from GitHub or Homebrew asks a version file whether a newer build exists, and verifies every update's signature before installing it. That request carries no identifier this app invents, and its count is the only measure this project has of how many people actually use it. Turn it off in Settings › General. The Mac App Store version does not do this — Apple delivers those updates, and the app contains no updater at all.

Permissions

Backpocket asks for the Accessibility permission for one reason: to paste into the app you were using, by sending a ⌘V keystroke. It is used for nothing else — not to read other apps, not to observe what you type. Turn "paste automatically" off and the permission is not needed; choosing an item simply puts it on the clipboard for you to paste yourself.

Children

Backpocket is a general-purpose utility. It collects no data from anyone, of any age.

Changes

If this policy ever changes, the change will appear here and in the app's release notes. The source code is public, so any claim on this page can be checked against what the app actually does.

Contact

Questions or concerns: open an issue on GitHub.

Backpocket — 개인정보 처리방침

최종 수정: 2026년 9월 2일

Backpocket은 클립보드 관리 앱입니다. 사용자가 복사하는 모든 것을 보게 되는 앱이므로, 이 문서는 길고 모호하기보다 짧고 구체적입니다.

수집하는 정보

없습니다. 계정도, 로그인도, 동기화도, 분석 도구도, 텔레메트리도, 크래시 리포트도 없습니다. 복사하거나 작성한 내용을 보관하는 이 프로젝트의 서버는 존재하지 않습니다.

데이터가 저장되는 곳

클립보드 기록과 메모는 사용자의 Mac에만 저장됩니다. 위치는 ~/Library/Application Support/Backpocket이며, App Store 버전은 앱 전용 샌드박스 컨테이너 안입니다. 그 폴더를 지우면 데이터도 함께 사라지고, 어디로도 업로드되지 않습니다.

의도적으로 기록하지 않는 것

다른 앱이 "이건 저장하지 말라"고 표시하는 클립보드 마커를 존중합니다 — 비밀번호 관리자가 사용하는 org.nspasteboard.ConcealedType, 그리고 TransientType, AutoGeneratedType입니다. 이렇게 표시된 내용은 저장하지 않고 무시합니다. 특정 앱을 통째로 제외할 수도 있으며, 그 앱에서 복사한 것은 전혀 기록되지 않습니다.

네트워크를 사용하는 경우

인터넷으로 나가는 것은 두 가지뿐이고, 둘 다 사용자가 끌 수 있으며, 복사한 내용을 담아 보내지 않습니다.

링크 파비콘. 저장된 링크를 표시할 때 해당 사이트의 아이콘을 HTTPS로 요청할 수 있습니다. 링크가 가리키는 도메인에 직접 요청하며, 제3자 파비콘 서비스를 거치지 않고, 로컬이나 사설 주소에는 요청하지 않습니다. 이 요청에는 일반적인 웹 요청이 담는 것(IP 주소와 시각) 외에 사용자에 관한 정보가 없으며, 쿠키를 저장하지 않는 세션으로 이루어집니다. 설정 › 클립보드에서 끄면 요청 자체가 발생하지 않습니다.

업데이트 확인 (직접 다운로드판만 해당). GitHub이나 Homebrew로 받은 버전은 새 버전이 있는지 확인하는 파일을 요청하고, 설치 전에 모든 업데이트의 서명을 검증합니다. 이 요청에는 앱이 만들어낸 식별자가 담기지 않으며, 그 횟수가 이 프로젝트가 실제 사용자 수를 아는 유일한 방법입니다. 설정 › 일반에서 끌 수 있습니다. App Store 버전은 이 동작을 하지 않습니다 — 업데이트는 애플이 전달하며, 앱에 업데이터 자체가 들어 있지 않습니다.

권한

손쉬운 사용 권한을 요청하는 이유는 하나입니다. 사용하던 앱에 ⌘V 키 입력을 보내 붙여넣기 위해서입니다. 다른 용도로는 쓰지 않습니다 — 다른 앱의 내용을 읽지도, 입력을 감시하지도 않습니다. "자동으로 붙여넣기"를 끄면 이 권한이 필요 없으며, 항목을 고르면 클립보드에 올라가고 붙여넣기는 직접 하시면 됩니다.

아동

Backpocket은 범용 유틸리티이며, 연령과 무관하게 누구의 데이터도 수집하지 않습니다.

변경

이 방침이 바뀌면 이 페이지와 앱의 릴리스 노트에 반영합니다. 소스 코드가 공개돼 있으므로, 이 문서의 모든 주장은 앱의 실제 동작과 대조해 확인하실 수 있습니다.
